Significance on a Smoothing Grid — the iPOP Aging Crest Statistics

Generated: 2026-08-08  |  A single-finding report; the complete audit (seven findings) is at iPOP Aging — Audit Report  |  Code: jaspershen-lab/ipop_aging (235 R scripts)  |  Data: Nature Aging supplementary tables (MOESM3) + repository objects  |  Paper: Shen et al., Nature Aging (2024)
Audit by Natural Joints
Bottom line. The statistical evidence for the reported aging crests near ages 44 and 60 is not valid as reported. The significance tests behind them consume 91 LOESS-interpolated grid points as if they were independent observations, while the real support for a window arm is as few as 6–9 participants; the attainable significance is an exact function of the interpolation density alone, 2/C(2k,k) for k grid points per arm; 17.9% of the 293,930 deposited test results sit exactly at the published setting’s floor; and the full pipeline produces significant crests from pure-noise input.

The same defect was established independently, six weeks earlier, by Carbonneau et al. — by the opposite kind of argument. Theirs is a mathematical demonstration on constructed data, not derived from the deposited record; ours is a systematic examination of the deposited code and data. This report presents the finding and the route by which a data-first audit reached it.
Prior work. Carbonneau et al., “LOESS and DE-SWAN can induce artifactual ‘waves’ of molecular aging” (bioRxiv, 2026-06-28), co-authored by two authors of the original paper, establishes the same central defect by simulation. The first author of the original paper has since publicly acknowledged the permutation defect as “an honest methodological mistake.” The finding reported here is therefore not novel; what is new is the empirical route to it, the closed-form and fingerprint results below, and the attribution they license.

Method

Three phases, run in order, followed by two adversarial passes. The two audits in Phase 2 were mutually independent: each worked from its own reference frame with no access to the other’s output. All phases were executed by Claude Fable 5.

Phase 1 — Semantic enrichment of the deposited data

Input: the nine deposited tables. No analysis code, no paper text. Each table is characterized from its contents alone: its grain (what a single row represents), which columns function as identifiers rather than measurements or classifiers, and whether tables sharing a key agree on the columns they have in common. A table whose contents are impossible for the entity its name claims is flagged. Output across the nine tables: 225 defects — 223 column-level warnings and 8 table-level failures.

Phase 2 — Two independent audits against the code

Claims vs. code holds the published text against the deposited scripts: does the program do what the paper says it does? Code vs. data holds the scripts’ assumptions against the files they read: do the program’s preconditions hold on the actual data? Both had the Phase-1 output available; neither was restricted to it.

Phase 3 — Verification and adversarial review

Every claim was re-checked by recomputation against the raw CSVs with an independent toolchain; the deposited R scripts were analyzed but not executed. Two adversarial passes then attempted to refute every finding — one against the primary artifacts, one against the paper’s full text on argument logic; refuted sub-claims were removed, and the corrections are recorded in the full report.

The route to the finding

What the data-only pass issued

First, what “the data” is. A deposited package is not a study’s raw input; it is whatever the analysis workflow exported at the end — measurement tables, annotation tables, and, unmarked among them, the workflow’s own intermediate products. Phase 1 does not assume this decomposition; it recovers it, by asking of each table whether its contents are possible for the entity its name claims.

On one table the answer was no. Three failures, raised with no access to any code or method description:

FailureReported, verbatim
Ambiguous grain“The table claims a grain of ‘one row per sample_id’, but the sample_id column contains age points, not unique identifiers.”
Domain coherence“subject_id is resolved as a classifier but holds the constant string 'Subject', meaning it does not contain a subject identifier.”
Role coherence“PK 'sample_id' votes 'sample', but 1 body column(s) unanimously imply 'subject' (age→subject).”

No process that samples human beings produces this shape — measurement yields ragged ages, distinct identifiers, many subjects — and every deterministic interpolation over an age axis produces exactly this shape. The flags describe a table that is impossible as a record of the world and inevitable as the output of a smoother. What the data-only pass detected was therefore not dirty data: it was the pipeline itself, materialized in the data layer — the method’s intermediate, exported into the deposit under the name of a sample table. Reading this table is reading the method.

None of the three flags names LOESS — the pass has no access to the method, so it can report the impossibility but not its cause. Two calibration facts constrain the claim. First, each individual note was issued as an ordinary warning — hygiene advice of the kind a reader skims past; the FAIL verdicts came from a composition step that read the notes together: a key that is a measurement, a subject column containing one subject, and a body column implying a different entity than the key. No single flag was decisive. Second, what the flags establish is a necessary condition — a signature consistent with a generated grid — not yet the identification of which procedure generated it or which tests consumed it. The remaining steps close that gap.

What the code audits established

The flagged table is sample_info.csv: 91 rows spanning ages 30.0 to 75.0 in exact 0.5-year steps, sample_id equal to age on every row, subject_id the constant "Subject" — a LOESS prediction grid, generated at 2_loess_fit_cross_section.R and exported into the deposit under the name of a sample table. Both code audits traced its consumption: do_se_swan (100-tools.R:634) pulls its test variable from this object’s sample_info; the call site (cross_sectional_loess/DE-SWAN2.R:33–44) runs window centres 40–65 with 20-year windows over it; the DEG tests (5_clinical_test/3_DEG.R) and the age correlations (5_correlation_with_age.R:60–83, Spearman on as.numeric(sample_id)) load the same grid objects. Three test families, one interpolated input.

What verification added

  • The closed-form floor. At complete separation the two-sided Wilcoxon rank-sum p is exactly 2/C(2k,k), where k is the number of grid points per window arm — a quantity set by the interpolation step, not by the biology: k = 10 (1.0-year step) → 1.1×10−5; k = 20 (the published 0.5-year step) → 1.45×10−11; k = 100 (0.1-year step) → 2.2×10−59.
  • The fingerprint in the deposited cache. The repository contains the cached DE-SWAN output: 293,930 tests (11,305 molecules × 26 window centres). Its minimum p equals the k = 20 floor to nine digits, and 17.9% of all tests sit exactly at that floor. Tests run on participants could not produce this structure: per-window arm sizes vary from 6 to 42 across centres, so the floor would differ at every centre. The deposited results were computed on the grid — established from the deposit itself, without executing anything.
  • Effective sample size. The number of participants actually contributing to a window arm is as few as 6 (centre 40) and 7–9 inside crest-1 windows — against 20 interpolated points per arm at the published step.
  • The null simulation. The full pipeline — LOESS, half-year grid, sliding Wilcoxon, per-centre FDR — run on pure-noise molecules over the cohort’s real age distribution puts 59–88% of them below q < 0.05 and generates crests of its own. An independent re-run during adversarial review reproduced this (66–80% across LOESS spans) together with the two-hump, mid-50s-trough shape of the real curve; the crest ages produced by noise vary from run to run, which is itself the point.
  • The permutation block. The validation that could have caught this is commented out (DE-SWAN2.R:416–477) — and shuffles ages after the LOESS step, an invalid null, since points on a fitted curve are not exchangeable with respect to age.

The finding

The crest significance tests operate on LOESS-derived grid points rather than independent participants
VERIFIED INDEPENDENTLY ESTABLISHED CRITICAL
Rule typePseudoreplication — derived values analyzed as independent observations Location100-tools.R:634; cross_sectional_loess/DE-SWAN2.R:33–44, 416–477; DE_SWAN/temp_data; 5_clinical_test/3_DEG.R; 5_correlation_with_age.R:60–83; sample_info.csv

Fact. The object the significance tests consume is not a sample table but a LOESS prediction grid published under the name of one. The Wilcoxon sliding-window tests, the DEG ANOVA/t-tests, and the grid Spearman correlations all treat its 91 interpolated points as independent samples.

Consequence. The effective sample size of any window is the number of participants contributing data to it — 6 to 9 where the crests live — not the number of interpolated points it contains.

Blindness to the claimed contrast. The smoothed curve makes within-window rank ordering nearly deterministic: any drift that fully separates the arms returns the same floor p regardless of effect magnitude, so a purely linear age effect produces it as readily as a sharp non-linear one. The statistic used to establish non-linearity does not distinguish non-linear change from linear change. Saturation alone does not localize crests — the crest is a property of the significant-count curve across centres — which is why the causal claim rests on the null simulation, not on the floor.

Dependence on a free parameter. The attainable significance is 2/C(2k,k) in the grid step; the deposited cache’s minimum p matches the published step’s value to nine digits, with 17.9% of all 293,930 tests exactly at it. The reported significance is not invariant to an arbitrary numerical parameter of the interpolation grid.

Causal validation. Pure noise through the same pipeline yields 59–88% significance and crests of its own.

Effect on paper claims. This is the inference layer beneath the paper’s central result. The claim at risk is not that the molecules were measured incorrectly, but that the reported crests represent a detected biological signal: on the deposited pipeline, a dataset with no age signal yields comparable significance counts and comparable crests. Downstream, the crest molecule sets feed the pathway enrichment and correlation-network analyses, which inherit the q-values.

Point-by-point convergence

Each Phase-1 failure on sample_info.csv has a counterpart in the preprint, stated in a different vocabulary — one route reading the artifact, the other simulating the procedure that made it:

Reported here, from the file aloneCorresponding observation in Carbonneau et al.
Ambiguous grain. The sample_id column contains “age points, not unique identifiers.” “LOESS-interpolated values are derived estimates, not independent observations, and should not be analyzed as though they were measured data.”
Domain coherence. subject_id “contains exactly one distinct value 'Subject' across 91 rows.” “Each point along the curve is estimated relative to the same dataset and constrained to follow a smooth trajectory.” — there is no distinct person behind any row, and the file states it literally.
Exact duplicate columns. “Columns [sample_id, age] are exact duplicates”; downstream code “treats the duplicate as an independent feature.” “A statistical test assuming independent data points is instead being used on highly correlated data.”
Redundant data columns. The two columns are “perfectly correlated with a constant ratio” — 30.0 to 75.0 in fixed steps. “This artifactual trend is amplified when LOESS is used to interpolate data points across a uniform grid of points positioned every 0.5 years.” — the preprint describes the grid as a procedure it simulated; the same grid is materialized in the deposited file.
Granularity misinterpretation. “Analysts counting rows may overstate population size.” The effective sample size in a window is the number of contributing subjects, not the number of grid points; counting grid points yields hundreds of false discoveries per window centre.
Role coherence and name collision (subject_id denotes different entities in CLINICAL_INFO and SAMPLE_INFO). No counterpart. These locate the seam — the point in the pipeline where people become curve coordinates. The preprint treats the grid as self-evidently a grid, since it reasons about a procedure rather than a received file.

Scope and reading guide

This report treats one finding. The complete audit of the same deposit — six further findings covering the cohort table, the published clusterings, identifier integrity, and the supporting analyses, with an evidence ledger and novelty status for each — is at iPOP Aging — Audit Report.

Nothing here claims the underlying measurements are wrong, and nothing rules out non-linear molecular aging as a phenomenon — Carbonneau et al. are explicit on that point as well. What is established is narrower and sharper: the published statistical evidence for crests at 44 and 60 is generated by the analysis configuration rather than demonstrated by it, and this is provable from the deposited record alone, in closed form, by anyone.
